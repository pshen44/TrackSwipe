# 🎵 TrackSwipe – Swipe-Based Spotify Playlist Manager

***IN BETA***

Got a playlist (or two) with those *filler* songs that you skip every time you hear them? Use TrackSwipe! Remove those songs you got bored of long ago.

TrackSwipe is a web app that lets you manage your Spotify playlists using a card-swipe interface. Swipe left to remove songs, right to keep them. Not sure? Listen to the song with a simple click, then decide. Once done, apply changes directly to your Spotify playlist.

If you want to keep the songs you removed, don't worry, you can choose to like them, put them in another playlist, etc.

## 🚀 Features

- 🔐 **Spotify Login via OAuth (PKCE)**
- 🎧 **Preview songs** directly in-browser (no Spotify Premium required)
- 👆 **Swipe left/right** to mark tracks for removal or keeping
- ⏪ **Undo swipe actions** anytime before applying
- 🗑 **Apply all removals** to your Spotify playlist with one click
- 🖼 **Album art & artist info** for every song
- 🖐 Fully responsive, touch and mouse friendly

## 🔧 Tech Stack

- **Frontend**: React + TypeScript
- **Styling**: styled-components
- **Gestures**: react-swipeable
- **Audio Playback**: Native HTML5 `<audio>` via Spotify's `preview_url`
- **Spotify API**: Authorization, playlist read/write, playback setup
